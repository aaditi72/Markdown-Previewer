# Markdown Previewer

## 📌 Introduction
Markdown Previewer is a simple and interactive web application that allows users to write and preview Markdown in real time. It provides a seamless experience for users to convert Markdown syntax into formatted HTML effortlessly.

## 🚀 Features
- **Live Preview**: Instantly see the rendered Markdown output as you type.
- **Syntax Support**: Supports GitHub Flavored Markdown (GFM), including tables, lists, and more.
- **Reset Functionality**: Quickly clear the editor and reset to the default template.
- **Responsive Design**: Works across various screen sizes for an optimal experience.

## 🛠️ Technologies Used
- **React.js**: Frontend framework for building a responsive UI.
- **React-Markdown**: Renders Markdown to HTML.
- **Remark-GFM**: Adds GitHub Flavored Markdown (GFM) support.
- **CSS**: Custom styling for a clean and interactive user experience.

## 📥 Installation & Setup
### Prerequisites
Ensure you have **Node.js** and **npm** installed on your system.

### Steps to Run the Project
1. **Clone the repository**:
   ```sh
   git clone https://github.com/aaditi72/Markdown-Previewer.git
   cd Markdown-Previewer
   ```
2. **Install dependencies**:
   ```sh
   npm install
   ```
3. **Start the development server**:
   ```sh
   npm start
   ```
4. Open **http://localhost:3000/** in your browser.

## 🛠 Usage
- Type Markdown text in the **editor**.
- The formatted output appears in the **preview** section instantly.
- Click the **Reset** button to clear the editor.
